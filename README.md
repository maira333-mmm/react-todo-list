# TaskFlow Pro - Professional Task Management Application

A production-ready, feature-rich task management application built with React and Vite.
https://react-todo-list-o3jx-hzbvhxevx-mairas-projects-0f919ce8.vercel.app/

## 🚀 Features

### Core Features
- ✅ Create, Read, Update, Delete tasks
- ✅ Mark tasks as complete/incomplete
- ✅ Priority levels (Low, Medium, High)
- ✅ Due dates for tasks
- ✅ Tags system (up to 5 tags per task)
- ✅ Search functionality
- ✅ Advanced filtering (All, Active, Completed, by Priority)
- ✅ Sorting (by Date, Priority, Title)
- ✅ List/Grid view toggle
- ✅ Local storage persistence
- ✅ Responsive design (mobile & desktop)

### Analytics Dashboard
- 📊 Total tasks count
- 📈 Active tasks
- ✅ Completed tasks
- 📉 Completion rate with progress bar
- 🔴 High priority tasks count
- ⚠️ Overdue tasks indicator

### UX Enhancements
- 🎨 Modern gradient design
- ✨ Smooth animations
- 🔔 Delete confirmation modal
- ⌨️ Keyboard shortcuts (Escape to close modals)
- 📱 Touch-friendly interface
- 🌙 Cross-tab synchronization

## 🛠️ Tech Stack

- **React 18** - UI Library
- **Vite** - Build tool
- **CSS Modules** - Scoped styling
- **LocalStorage API** - Data persistence

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/taskflow-pro.git

# Navigate to project directory
cd taskflow-pro

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
